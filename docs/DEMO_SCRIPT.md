# Three-minute demo storyboard

## 0:00–0:25 — Landing

Open `/`. Show the PAIRWISE hero and five-stage workflow strip. Emphasize consenting adults and evidence-grounded agents.

## 0:25–0:55 — Demo entry

Open `/demo`. Point to the **SYNTHETIC DEMO** banner. Note: 25 synthetic participants, 300 sessions, 600 ranking rows, no API key required.

## 0:55–1:30 — Profile analysis

Click **Browse a profile**. Show LinkedIn/Instagram source panels, acquisition method, summary, interests with evidence quotes, confidence bars, and unknowns. Stress that synthetic ≠ verified real.

## 1:30–2:15 — Dating room

Return to demo → **Watch example date**. Show dual-sided transcript, turn counter, demo-replay badges on messages, shared interests, score breakdown, and date report.

## 2:15–2:45 — Rankings

Open rankings for the participant. Show rank 1…N with scores, confidence, why/friction/unknown, and link into a transcript. Switch to another participant to show personalization.

## 2:45–3:00 — Live path

Visit `/settings`. Explain that live mode needs `LLM_API_KEY` plus consented authorized profile text when platforms block automated access.
